# K-22 publication review

The automated lint rejects unusually long criterion/interpretation literals, but copyright review cannot be reduced to character counting. Before release, a reviewer must record that:

- source text is referenced by Source, SourceEdition and SourceLocation rather than copied;
- Criterion statements and Interpretation propositions are author-written paraphrases;
- any necessary quotation is short, attributed and legally reviewable;
- fixture data contains no protected standard text;
- the reviewer, date and release version are recorded in the release evidence.

An unchecked review blocks publication even when `publication_lint.py` passes.
