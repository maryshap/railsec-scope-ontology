# Legacy migration decisions

`legacy-rule-triage.csv` contains one explicit implementation, gap-closure, future-version, or retirement decision for each of the 54 rules actually returned by the legacy generator. The matrix is generated by `scripts/write_legacy_rule_triage.py` so the recorded status can be refreshed deliberately as Phase 2 closes.

No rule is copied unchanged. `implemented` means the legacy intent is already covered by the RSSO Phase 2 criteria/rule pipeline with source records in the ontology. `implement-now` means the source is identified and the remaining work is a small admitted ontology-complete gap. `future-version` means the rule belongs to a later L3, reachability, numeric-comparison, or ordering follow-up. `retire-or-out-of-scope` means the rule is not admitted as a Phase 2 ontology rule and the reason is recorded in the row.
